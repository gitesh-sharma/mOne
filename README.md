# mOne — Merahi Village

mOne is an offline-first Android/PWA application for Merahi Village.

### V1
- Capacitor Android shell
- Green glassmorphism UI with icon-first navigation
- Offline crop calendar, village facts, places and scheme resources
- Gemini multimodal crop photo analysis (optional user-provided API key)
- Open-Meteo live weather
- On-device GPS field area measurement
- Fertilizer and irrigation calculators
- Market and official scheme resource board
- Emergency/community board foundation
- Social, About, Contact and legal pages

### Android
```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

Never commit a Gemini API key to the repository.
